Earthenware Shift Machine

An 8-bit computer built around ×2. Every shift moves the accumulator one bit left. Load a program, then step through it and watch the bits move.

Instruction set

Each instruction is one byte: 3 bits of opcode, then a 5-bit address.

HALT000Stop the machine.
LDA a001Load memory[a] into A.
STO a010Store A into memory[a].
ADD a011A = A + memory[a]. Carry is set on overflow. Add 255 to subtract 1.
SHL100A = A × 2 (shift left). The bit that falls off goes to carry.
JZ a101Jump to a if A is zero.
JMP a110Jump to a.
JC a111Jump to a if carry is set.
DB nPut the value n (0–255, or negative) in memory. Labels end with a colon; comments start with a semicolon.
